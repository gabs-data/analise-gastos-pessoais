# Análise de Gastos Pessoais

## Objetivo
Analisar padrões de consumo e comportamento financeiro utilizando dados.

## Tecnologias
- Python (Pandas)
- SQL (SQLite)
- Power BI

## Análises realizadas
- Gastos por categoria
- Evolução mensal de despesas
- Identificação de maiores gastos
- Padrões de consumo

## Insights
- Gastos recorrentes impactam significativamente o orçamento
- Algumas categorias concentram a maior parte das despesas

## Estrutura
- dados: base de dados
- codigo: análise em Python
- dashboard: visualizações

Projeto desenvolvido para aprendizado em análise de dados.
